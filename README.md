# 🛒 Amazon E-Commerce Clone

A responsive e-commerce website inspired by the Amazon shopping interface, built using HTML and CSS.

## 🌐 Live Demo

[View Live Demo](https://nisha386.github.io/amazon-e-commerce-clone/)

## 📌 About the Project

This project is a frontend clone inspired by Amazon's website. It was created to practice web development concepts such as page structure, styling, navigation, layouts, product sections, and responsive design.

## ✨ Features

- 🏠 Amazon-inspired homepage
- 🔍 Search bar
- 📦 Product cards and product sections
- 🛍️ Shopping-style interface
- 📱 Responsive layout
- 🎨 Styled navigation bar and sections
- 🖼️ Product images and categories

## 🛠️ Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling and layout
- Flexbox – Page and component alignment
- Git & GitHub – Version control and project hosting
- GitHub Pages – Live website deployment

amazon-ecommerce-clone/

## 🚀 How to Run Locally

1. Clone this repository
2. Open the project folder.
3. Open "index.html" in your browser.

## 🎯 Purpose

The main purpose of this project is to improve my understanding of HTML, CSS, responsive web design, and frontend development by recreating the layout of a popular e-commerce website.
